Aetheris — your keys never live in .env again.

The secrets operating system: one encrypted vault, one local LLM gateway that injects provider keys at request time, zero-knowledge sync to every device. Open source · self-hosted · C#/.NET 8.

GitHub repo ↗ Live click-preview ↗

⚡ The LLM gateway

One OpenAI-compatible endpoint (127.0.0.1:7474/v1) for every tool you use. Keys come from the encrypted vault at request time — never from .env, shell history, or client code. Model aliases with fallback chains, tokens/day budgets, redaction-first logs. Works with OpenAI, Anthropic, and local Ollama models.

🗄️ Zero-knowledge vault

Passwords, API keys, SSH items, TOTP. Argon2id → XChaCha20-Poly1305 per item. The server only ever sees ciphertext.

⌨️ aeth CLI

aeth run --env OPENAI_API_KEY=<ref> -- cmd — injects secrets into child processes only. Lineage: KEY-BITCHER.

🌐 One PWA, all devices

Web/desktop/mobile from a single client. Installable, offline-first, auto-locking.
