# Integrations

Shell wrappers, browser extension manifests, and IDE integration files.

## Terminal Wrappers

- `terminal/aetheris.cmd` — Windows Command Prompt wrapper
- `terminal/aetheris.ps1` — PowerShell wrapper
- `terminal/aetheris.sh` — Unix shell wrapper

## System Integration

- `system/env-loader.ps1` — Loads Aetheris environment variables in PowerShell
- `system/env-loader.sh` — Loads Aetheris environment variables in Bash
- `system/install-path.ps1` — Installs Aetheris to system PATH (Windows)
- `system/install-path.sh` — Installs Aetheris to system PATH (Unix)

## Browser Extensions

- `browser/chrome/` — Chrome/Edge/Brave extension (Manifest V3)
- `browser/firefox/` — Firefox extension (Manifest V3)
- `browser/safari/` — Safari extension (Xcode project)
- `browser/edge/` — Edge extension (Manifest V3)

## IDE Integrations

- `ide/vscode/` — VS Code extension and settings
- `ide/jetbrains/` — JetBrains plugin configuration
