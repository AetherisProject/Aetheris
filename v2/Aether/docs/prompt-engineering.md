# 🎯 Prompt Engineering: How to Get the Best Results from AI

## What is a Prompt?

A prompt is simply the text you enter to tell AI what you want. The better your prompt, the better the results.

---

## 📝 The Anatomy of a Good Prompt

### 1. **Role** (Who should AI be?)
- "Act as a professional copywriter"
- "You are a Python expert"
- "Pretend you're a 5th grade teacher"

### 2. **Task** (What should AI do?)
- "Write a blog post"
- "Create a Python function"
- "Explain this concept"

### 3. **Context** (What information does AI need?)
- "For a tech startup targeting developers"
- "Using this specific data: [data]"
- "Based on this document: [text]"

### 4. **Constraints** (What limits should AI follow?)
- "In 500 words or less"
- "Using only Python standard library"
- "For a beginner audience"

### 5. **Format** (How should the output look?)
- "As a Markdown table"
- "In JSON format"
- "As a bullet point list"

---

## 🌟 Prompt Formulas

### Formula 1: The Classic
```
[Role] + [Task] + [Context] + [Constraints] + [Format]
```

**Example**:
```
Act as a professional marketing copywriter. Write a product description for a new smartphone. Target audience is tech-savvy millennials. Keep it under 200 words. Format as a bullet point list of key features.
```

### Formula 2: Step-by-Step
```
1. [First step]
2. [Second step]
3. [Third step]
```

**Example**:
```
1. Analyze this dataset
2. Identify the top 5 trends
3. Create a summary report
4. Suggest 3 actionable insights
```

### Formula 3: The Template
```
Use this template: [template]
Fill in: [variables]
```

**Example**:
```
Use this template for a press release:

FOR IMMEDIATE RELEASE

[Headline]

[City, Date] - [Company] today announced [main news].

[Quote from CEO]

About [Company]: [brief description]

Fill in the details for a new product launch.
```

## 🎨 Prompt Techniques

### 1. Few-Shot Prompting
Give AI examples of what you want:

**Example**:
```
Here are examples of good product names:
- Tech: Nova, Quantum, Fusion
- Food: Zesty, FreshBite, PureDelight
- Fashion: Elegance, TrendSet, StyleCraft

Now create 5 product names for a new fitness app.
```

### 2. Chain-of-Thought
Ask AI to explain its reasoning:

**Example**:
```
Solve this math problem and explain each step:
If a train leaves Station A at 60 mph...
```

### 3. Temperature Control
- **Low temperature (0.2-0.5)**: More deterministic, consistent
- **High temperature (0.8-1.2)**: More creative, varied

### 4. Persona Prompting
Give AI a personality:

**Example**:
```
You are a wise old sage who gives advice in the form of ancient proverbs. Give me advice about starting a new business.
```

## 📊 Prompt Examples by Use Case

### Writing
- "Write a blog post about [topic] in [style] for [audience]"
- "Create a social media post for [platform] about [topic]"
- "Write a poem in the style of [poet] about [theme]"

### Coding
- "Write a Python function that [does X]"
- "Debug this code: [code]"
- "Explain how this algorithm works: [code]"

### Learning
- "Explain [concept] to a [age/level]"
- "Create a study guide for [topic]"
- "Give me 10 interview questions about [topic]"

### Business
- "Create a marketing plan for [product]"
- "Analyze this business data: [data]"
- "Write a business email to [recipient] about [topic]"

## ⚡ Advanced Tips

### 1. Iterative Refinement
Start with a simple prompt, then refine:
```
First: "Write a story"
Then: "That's good, but make it more exciting"
Then: "Add a twist ending"
Then: "Make the main character more relatable"
```

### 2. Multi-Part Prompts
Break complex requests into parts:
```
Part 1: Research [topic]
Part 2: Create an outline
Part 3: Write the first draft
Part 4: Edit and refine
```

### 3. Constrained Creativity
Give AI creative freedom within bounds:
```
"Write a short story set in a dystopian future where robots have taken over. The main character must be a 12-year-old girl. The story must have a hopeful ending. Keep it under 1000 words."
```
