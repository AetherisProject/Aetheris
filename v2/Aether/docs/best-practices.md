# ✅ AI Best Practices Checklist

## Before You Start
- [ ] I have a clear goal for what I want to achieve
- [ ] I know my audience (if applicable)
- [ ] I have all the necessary context/information
- [ ] I've chosen the right AI model for my task

## Writing Good Prompts
- [ ] My prompt is specific and detailed
- [ ] I've included relevant context
- [ ] I've specified the desired format
- [ ] I've set appropriate constraints (length, style, etc.)
- [ ] I've considered the AI's limitations

## Getting Good Results
- [ ] I've reviewed the output for accuracy
- [ ] I've verified any facts or claims
- [ ] I've refined the output if needed
- [ ] I've checked for biases or problematic content
- [ ] I've made sure the tone is appropriate

## Using AI Responsibly
- [ ] I'm not using AI to cheat or plagiarize
- [ ] I'm not using AI to spread misinformation
- [ ] I'm not using AI to impersonate others
- [ ] I'm not using AI for harmful purposes
- [ ] I'm giving credit where appropriate

## After Getting Results
- [ ] I've saved my work (if needed)
- [ ] I've provided feedback to improve future results
- [ ] I've shared useful results with others (if appropriate)
- [ ] I've learned from the experience

## 🎯 Golden Rules

1. **Garbage In, Garbage Out**: The quality of your prompt determines the quality of your results
2. **AI is a Tool, Not a Replacement**: Use AI to enhance your work, not replace your thinking
3. **Verify, Verify, Verify**: Always double-check AI-generated information
4. **Iterate**: The first result is rarely the best - refine and improve
5. **Experiment**: Try different approaches to see what works best
