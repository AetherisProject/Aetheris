How It Works

Simple, secure, and under your control

1

Initialize Vault

Run aeth init to create your encrypted vault. Your master password derives the encryption key using Argon2id.

2

Add Your Keys

Store API keys with aeth add <name>. Each key is encrypted and stored securely in your vault.

3

Start Gateway

Launch the gateway with aeth gateway. It listens on localhost and proxies requests to your providers.

4

Use Your Tools

Run aeth run -- curl ... or configure your apps to use the gateway. Keys are injected securely at runtime.
