# Features

## SSH Terminal
- xterm.js rendering with GPU acceleration
- Vault-integrated connections (no ~/.ssh/config needed)
- Tabbed sessions and split panes
- Session recording and playback
- Collaborative sessions (pair programming)
- Smart snippets with variables
- Integrated SFTP browser
- Port forwarding with visual map
- Connection health monitoring
- AI-powered command suggestions (local)
- 50+ themes with marketplace

## Password Vault
- Zero-knowledge XChaCha20-Poly1305 encryption
- Breach monitoring (HaveIBenPwned)
- Auto-password-change on breach detection
- Password strength analysis
- Built-in TOTP authenticator
- Password generator
- Custom fields and tags
- Favorites and history

## API Key Manager
- 30+ provider support
- Auto-rotation before expiry
- Health monitoring per provider
- Env var / config injection
- Rotation calendar
- Provider marketplace

## Browser Extension
- Chrome, Firefox, Safari, Edge, Brave
- WASM crypto (same Rust core)
- Password autofill
- API key autofill (provider dashboard detection)
- Works offline without desktop app
- Supercharged when desktop app is present

## Mobile
- iOS and Android (Flutter)
- Biometric unlock (Face ID, Touch ID, fingerprint)
- Autofill services
- TOTP authenticator
- QR code sync with desktop
- Push notifications for alerts

## Web App
- Full vault management
- Security dashboard
- Admin interface
- Team management
- Audit logs
- Debug panel

## Proactive Engine
- Auto-rotate API keys
- Auto-change passwords after breach
- Auto-monitor provider health
- Auto-sync across devices
- Auto-backup on schedule
- Auto-cleanup unused items
- Auto-update the tool
- Auto-remind and auto-alert
