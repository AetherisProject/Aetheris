03 / Foundation

Core System Pillars

The engineering tenets powering the Secrets Operating System.

Zero-Knowledge Architecture

Derived locally via Argon2id into XChaCha20-Poly1305. Master passwords and private keys are never stored on disk in plaintext or transmitted across wires unencrypted.

Moshi-Grade Performance

Compiled to bare-metal native binaries via Rust. Sub-millisecond terminal startup, instant key lookups, and minimal resource footprint.

Autonomous Orchestration

The Proactive Engine automatically monitors secret health, rotates aging provider API keys, and orchestrates zero-interaction SSH bootstrapping.
