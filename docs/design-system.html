Brand Identity Core

Aetheris is engineered as The Secrets Operating System — combining the slickness of modern terminal clients with zero-knowledge cryptography and proactive background automation.

Vision & Personality

  • Absolute Trust: Zero-knowledge client-side encryption. Secrets never leave the CPU in plaintext.
  • Velocity & Precision: Native Rust performance with sub-millisecond overhead.
  • Aesthetic Serenity: Deep void canvas illuminated by focused cyber-accents.

Typography

  • Primary Sans-Serif: Plus Jakarta Sans / Inter
  • High legibility across screen sizes and densities.
  • Weights: 400 (Regular), 500 (Medium), 600 (Semibold), 700/800 (Bold).
  • Code & Shell Monospace: JetBrains Mono
  • Used for terminal sessions, SSH fingerprints, API key identifiers, and token previews.

  3. Card Glassmorphism: Elevated dark surface containers with subtle border highlights on hover.
